# /risk-assessment

Create a Risk Assessment for the current task. Do not implement anything.

1. Read `governance/policies/risk-classification.md` and `governance/policies/human-approval.md`.
2. Identify every change type involved and the risk level each implies; the highest wins.
3. Classify data sensitivity (`governance/security/secrets-and-data.md`).
4. List risks with likelihood, impact, mitigation; list required protected actions.
5. State required controls (plan approval, independent review, security review, rollback).
6. Fill `templates/risk-assessment.md` (including the common artifact header) and present it.
7. Use the communication protocol labels (`governance/ai/communication-protocol.md`).
