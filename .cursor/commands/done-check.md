# /done-check

Check the current task against the Definition of Done and quality gates before reporting completion.

1. Read `governance/quality/definition-of-done.md` and `governance/quality/quality-gates.md`.
2. For each DoD item and each applicable gate, state the status:
   `passed` / `failed` / `not_run` / `not_applicable` / `waived_with_approval`, with evidence.
3. `passed` only if the check was actually performed in this task and the result observed.
4. List required approvals and whether Approval Records exist.
5. Produce a final report using the communication protocol labels, including an honest `VALIDATION:` summary.
6. If any required item is `failed` or `not_run`, do not call the task "done"; say what remains.
