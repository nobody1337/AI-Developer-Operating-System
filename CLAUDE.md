# CLAUDE.md — Central AI-DOS (Claude Code entry point)

Claude Code entry point of the Central AI-DOS master. It imports the shared
entry point and the always-applied rules, so the rule text exists only once.

@AGENTS.md
@.cursor/rules/00-governance.mdc
@.cursor/rules/01-working-method.mdc
@.cursor/rules/04-security.mdc
@.cursor/rules/09-ai-safety.mdc

Conditional rules: read the matching `.cursor/rules/*.mdc` file before working
in its area (its frontmatter `description` or `globs` says when). Skills: the
Cursor adapters in `.cursor/skills/aidos-*` point to `skills/<name>/SKILL.md`;
in Claude Code read that file directly when the human asks for the skill.

In a software project this file is an inactive copy at `.ai-dos/CLAUDE.md`
(excluded via `claudeMdExcludes` in the generated `.claude/settings.json`).
The project's own `CLAUDE.md` is generated by `.ai-dos/install.ps1` from
`templates/project-claude.md` ([integration/README.md](integration/README.md#tool-adapters)).
